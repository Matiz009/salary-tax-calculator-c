# Salary and Tax Calculator (C)

A C program that works out an employee's pay and income tax from their pay scale, age and experience.

## Features

- Pay scales `W`, `X`, `Y` and `Z`, each with its own basic pay
- Running pay: basic pay plus a yearly increment for each year of experience
- Allowances: house rent, social security, and adhoc relief for employees over 45
- Gross pay, annual pay and the income tax on it

## Tech stack

C

## Getting started

```bash
git clone https://github.com/Matiz009/salary-tax-calculator-c.git
cd salary-tax-calculator-c
gcc "netSalaryCalculator.c" -o netSalaryCalculator && ./netSalaryCalculator
```
